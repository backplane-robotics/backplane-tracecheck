# Third-party dependencies and provenance

Backplane Tracecheck is licensed under Apache-2.0 (see LICENSE). Its runtime dependencies are declared in `pyproject.toml` and installed from PyPI. None are vendored into this repository:

| Package | Tested version | Source | License note |
|---|---|---|---|
| mcap | 1.5.0 | https://pypi.org/project/mcap/ | MIT; Foxglove Technologies Inc. Official Python writer, used only to generate the synthetic samples. |
| lz4 | 4.4.5 | https://pypi.org/project/lz4/ | BSD-3-Clause. Upstream LICENSE copied into docs/licenses/. Used for bounded LZ4 chunk decompression. |
| zstandard | 0.25.0 | https://pypi.org/project/zstandard/ | BSD-3-Clause. Upstream LICENSE copied into docs/licenses/. Used for bounded Zstandard chunk decompression. |

The MCAP reader (`tracecheck.reader`) is an independent implementation of the published MCAP specification and does not depend on mcap internals.

## Web app (`web/`)

| Component | Version | How it is used | License |
|---|---|---|---|
| fzstd (Arjun Barrett) | 0.1.1 | **Vendored** in `web/src/engine/vendor/fzstd.js`, with an added bounded `decompressInto` function. The original MIT header is retained in the file. | MIT |
| @noble/hashes (Paul Miller) | 2.x | Bundled from npm for streaming SHA-256. | MIT |
| Inter, Space Grotesk, JetBrains Mono (via @fontsource-variable) | 5.x | Self-hosted web fonts; no font CDN is contacted. | SIL Open Font License 1.1 |
| Vite, Vitest | 8.x, 5.x | Build and test tooling only; not shipped. | MIT |

The LZ4 frame decoder, CRC-32 and JSON compatibility layer in `web/src/engine/` are original code.

All bundled MCAP recordings are invented examples generated by tracecheck.samples. They include an unsupported-codec rejection case, malformed bytes and truncated bytes. They are not recordings of a real robot, safety incidents or customer environments. No third-party datasets or commercial robot schemas were included.
