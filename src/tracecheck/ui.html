Check whether a robot recording meets your recording contract. Get ten explicit checks, exact evidence locations, and a report you can keep.

1 · Choose a recording

MCAP, uncompressed or zstd/lz4 compressed · 64 MiB per file in this local UI (use the CLI or backplanerobotics.com for larger files) · 30 seconds.

Start with examples/clean.mcap, then try examples/faults.mcap. Both contain invented data.

3 · Review the evidence

PASS: evaluated requirement met.
WARN: limitation needs attention.
FAIL: requirement unmet or scan incomplete.
SKIPPED: no conclusion available.

Choose a file to begin.

2 · Set your recording contract

The demo contract expects one synthetic 10 Hz topic. Edit it for your recording. Only confirm clocks and sequence semantics you know. Nanosecond integers are kept exact.
