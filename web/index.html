Backplane Tracecheck

Check whether an MCAP recording meets your stated requirements for topics, metadata, message counts, rates, timestamp gaps, sequence continuity, and recording coverage. Review the findings and download JSON or HTML reports.

What is a recording contract? A recording contract is a checklist of the information and timing you expect in a recording. You choose the requirements; Tracecheck checks the file against them.

Recordings processed locally

The web app reads your file in slices inside a browser worker on your device. Recording files and reports are not uploaded.

Large recordings, streamed

Streams large recordings, subject to processing limits and available device resources. SHA-256 and CRC checks are computed as the file is read.

zstd & lz4, bounded

Compressed chunks are decoded with output capped at the declared size, and chunks that exceed it are rejected. These limits are tested; no parser can promise immunity to every malicious file.

Fast mode

Reads only the file summary for a quick inventory, message counts, schemas and metadata. Message-level timing checks are skipped and no full-file hash is computed. Falls back to a full scan if the summary is missing.

Findings you can trace

Findings include relevant locations where available. Missing items are reported as gaps. Reports record contract and file hashes, which identify the exact bytes checked. Hashes do not establish authenticity.

CLI for pipelines

The same checks run as a Python CLI with CI-friendly exit codes. For supported inputs, the browser and CLI produce matching JSON reports, apart from timestamps and tool fields.

Results describe the checks performed on the supplied recording. They do not establish safety, legal or regulatory compliance, or overall suitability for a particular use.

Privacy

Your recording files stay on your device.

The Tracecheck web app reads your selected recording and runs its checks in your browser. Recording files and generated reports are not uploaded to Backplane. Reports are downloaded to your device when you choose to save them.

Recording data uploaded: 0 bytes
  • No account is needed to use the free recording checker.
  • Recording processing happens locally, without a cloud processing service.
  • The checker code is available for inspection on GitHub.
  • Feedback is optional and separate from recording processing.

If you send feedback, only the form fields shown to you are submitted to Backplane. Recordings, reports, contracts, and filenames are not attached automatically. Normal website and feedback requests may generate hosting-provider logs.

Release Evidence Preflight

A planned local tool for importing software bills of materials produced by existing tools, comparing releases, and identifying missing or inconsistent information in a release evidence package.

It will report file and metadata gaps for your team to review. It will not determine whether a product meets legal or regulatory requirements.

A software bill of materials, or SBOM, lists software components and versions used in a product.

Context: The CRA's main obligations apply from 11 December 2027. Certain manufacturer reporting obligations have applied since 11 September 2026. Requirements depend on the product and circumstances.

How it works

Self-service, start to finish.

Choose your files. Set your requirements. Run checks locally. Review and export the findings.

  1. 01

    Choose your files

    Select an MCAP recording on your device, or try one of the synthetic demo recordings.

  2. 02

    Set your requirements

    Pick a preset contract or write your own in plain JSON that you keep.

  3. 03

    Run checks locally

    The checks run in your browser or on your machine with the CLI. No account is needed.

  4. 04

    Review and export

    Read each finding and save JSON or HTML reports to your device when you choose.
