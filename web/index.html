Backplane Tracecheck

Check MCAP robot recordings against a written recording contract: required topics, schemas, metadata, rates, gaps, timestamp regressions, sequence breaks and time coverage. Every finding points to the exact byte offset as evidence.

Files stay on your machine

The web app reads your file in slices inside a browser worker. Nothing is uploaded, and the site's security policy blocks outside connections.

Multi-GB, streamed

Recordings are streamed with SHA-256 and CRC checks computed on the fly. No file-size cap. Memory use is bounded by explicit limits.

zstd & lz4, bomb-safe

Compressed chunks are decoded with output strictly capped at the declared size. Malicious "decompression bombs" are rejected, not expanded.

Fast mode

Reads only the file summary for an instant inventory, message counts, schemas and metadata check. It falls back to a full scan if the summary is missing.

Evidence, not opinions

JSON and HTML reports pin each finding to chunk and message offsets, and include a contract hash and file hash, ready for a vendor dispute or an audit trail.

CLI for pipelines

The same checks run as a Python CLI with CI-friendly exit codes. Browser and CLI produce identical JSON reports for the same inputs.

Run it in CI

Python 3.11+. Exit code 0 means pass, 1 means findings, 2 means an input or configuration error.

Privacy by architecture

Your recordings never leave your browser.

Robot recordings can contain camera feeds, floor plans and customer sites. So the Tracecheck web app has no server-side processing at all.

  • Static site. HTML, JavaScript and fonts only, all served from this domain. There are no analytics, trackers or third-party scripts.
  • Local worker. Files are read in 8 MiB slices by a Web Worker on your device.
  • Locked-down network. The Content-Security-Policy only allows connections back to this site, which hosts only the demo files.
  • Inspectable. The code is open source under Apache-2.0. You can read it, build it, or run it offline.
